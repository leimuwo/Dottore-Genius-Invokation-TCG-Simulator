## Gate 判定

**M2-C：未通过。**

- 80% Random 胜率：没有任何席位达到 80% 点估计；最高为 shaping seed2 P2 的 77.8%。其 Wilson 区间下界为 59.2%，不能证明达到目标。
- 训练前对比：部分训练模型优于 untrained，但 sparse seed0/2 与 shaping seed0/1 仍接近或等于 0 胜，整体不稳定。
- 三 seed 一致性：不满足。相同配置的结果从 0 胜到 19/27（P1）或 21/27（P2）大幅波动。
- 先后手均衡：P1/P2 均已独立运行并报告；席位交换没有消除上述 seed 方差。
- timeout 对照：失败模型的对局主要以 timeout 结束；该现象已被记录，未被包装成胜率提升。

M2-A 闭环与 M2-B 数值稳定性仍保持通过。当前证据表明训练基线尚未形成可复现的策略能力；下一步应诊断训练/动作建模或增加训练预算，不能宣称 M2 全部完成，也不应通过修改门禁阈值来验收。
