## 0. 为什么会有这份记录

初版提案里有三处需要修正，理由写在这里，避免以后有人"照初版实现"：

1. **"配对 rollout 让 GAE 抵消先后手"不成立。** GAE 是逐轨迹的
   `A_t = Σ(γλ)^l δ_{t+l}`，两条独立轨迹之间没有任何项相消；配对只改变**采样分布**，
   不改变**估计量**。所以训练侧不用配对，改用配额 + 侧别进入价值函数。
2. **`preferred_side` 不是卡组的固有属性**，它依赖对手池与当前策略，必须连测量条件一起存。
3. **100 局判不出先后手差。** 检出 δ=5%（α=0.05, power=0.8）约需 **1570 局/侧**；
   100 局/侧的标准误 0.05，95% CI 宽 ±10%，且 70% 超时会让有效样本再打三折。

## 1. T5'：卡组侧别画像 + 弱侧过采样

### 字段（`decks/<name>.json`）

```json
"side_profile": {
  "measured_against": "pool_v1",       // 对手池标识，换池必须重测
  "policy": "random|heuristic|self",   // 用什么策略测的
  "n_games_per_side": 1600,            // 每侧局数，>= 1570
  "first_winrate": 0.53,
  "ci95": [0.51, 0.55],
  "measured_at_commit": "<sha>",
  "label": "first|second|neutral"      // ci95 跨 0.5 则为 neutral
}
```

### 采样

- **过采样弱侧，不过采样先手**。理由：先手占优时先手局是**容易样本**，多喂容易样本会掩盖弱侧问题。
- 建议配额：弱侧 55–60%（对应强侧 40–45%）；`neutral` 保持 50/50。
- 配额写进 `runs/<run_id>/manifest.json`，否则事后无法复现训练分布。

### 与评估的关系（重要）

训练分布（弱侧更多）与评估分布（必须 50/50 或按真实赛制）**不同**。所以：
报表必须按侧别分层（T7），且**不许**把这种训练出来的模型与 50/50 训练的基线直接比总胜率。

## 2. T6'：训练不配对，评估配对

| 侧 | 做法 | 理由 |
|---|---|---|
| 训练 rollout | **不配对**：按配额采样侧别；侧别通过 `active_player_id` 进入 obs，并要求 value head 在两侧收敛到应有的偏移 | GAE 不吃配对；配对会白丢一半卡组/开局多样性 |
| 评估 | **配对**：同一 `(deckA, deckB, seed)` 跑两局交换座位，报告**配对差分**及其 CI | 同 seed = 公共随机数，配对差分方差显著低于两独立均值之差 |

补充：超时双负下总收益不再零和，所以配对求和 ≠ 0，差分统计要按座位分别算（`r_P1 − (−r_P2)` 这种写法禁止）。

## 3. T7'：两张表（**不含起手质量分桶**）

按用户决定，起手质量**不作为报表维度**。报表改为两张表：

| 表 | 行 | 列 |
|---|---|---|
| 表 1 按卡组 | 每套测试卡组 | 击杀胜率 / **超时率** / 平均 payoff / 95% CI |
| 表 2 按先后手 | 先手 / 后手（再按卡组细分） | 同上 |
| 摘要行 | 全部 | **总胜率、总超时率**（保留，作为 headline 数字） |

要求：

- 评估用**留出卡组**（`decks/test/`），不与训练池重叠；
- 每格给置信区间；预先登记"什么算有差异"的阈值，避免多重比较找噪声；
- 所有数字来自 `runs/` 账本离线重算，不许手工填。

### 起手质量：不建模，但要记账

- **不进报表、不进训练目标**；
- 每局把 `opening_hand`（排序后的卡名列表）+ 一个 `opening_score` 写进 `events.jsonl`；
- 将来若怀疑"胜率差来自起手运气"，可以直接从账本离线重算，无需重跑对局。

这就是事件账本的价值：**现在不建模 ≠ 以后算不出来**。

### 残余风险（必须承认）

起手质量从"报告维度"变成"未控制变量"，它仍可能系统性地偏向某套卡组或某个侧别。缓解手段按强度排：

1. **评估配对 + 同 seed**（已采纳）→ 配对差分里起手质量被共同随机数控制掉；
2. 两张表各加一列"**平均起手质量**"作为**诊断列**（不分组、不做检验）；
3. 若发现某卡组两臂的均值起手质量差 > 1 个标准差 → 该格结果标"不可解释"，回到 1 加大样本。
